# firebase1

Giao diện quản lý kho chuẩn doanh nghiệp (HTML/CSS/JS) theo yêu cầu:

- Giữ menu chính, bổ sung các tab: Tổng quan, Tồn kho, Nhập, Xuất, Lịch sử nhập xuất, Bán hàng, Nhà cung cấp.
- Quản lý thêm/bớt sản phẩm với các trường: SKU, tên sản phẩm, thương hiệu, phân loại (nếu là **Lọc** có trường **OEM**), số lượng, ngưỡng giới hạn, giá, vị trí.
- Hỗ trợ ảnh sản phẩm: upload trực tiếp hoặc chụp ảnh từ camera.

## Chạy thử

```bash
python3 -m http.server 8000
```

Mở `http://localhost:8000`.
