# Inventory Management Demo

Ứng dụng web tĩnh quản lý tồn kho đơn giản với các chức năng:
- Quản lý sản phẩm (thêm/xóa), thương hiệu, phân loại, vị trí lưu trữ.
- Theo dõi nhập/xuất kho.
- Danh sách nhà cung cấp.
- Menu xem nhanh: Tổng quan, Tồn kho, Nhập, Xuất, Nhà cung cấp.
- Upload ảnh sản phẩm (lưu dưới dạng Data URL trong localStorage).

## Chạy nhanh

Mở file `index.html` trực tiếp trên trình duyệt, hoặc dùng web server tĩnh:

```bash
python3 -m http.server 4173
```

Sau đó truy cập `http://localhost:4173`.
