# firebase1

Ứng dụng web tĩnh quản lý mã OEM thay thế:

- Tab **Tổng quan**: tìm/gợi ý mã OEM thay thế, hiển thị ảnh và xem ảnh bằng popup hình vuông + ảnh oval.
- Tab **Bán hàng**: cho phép chọn nhiều sản phẩm trên một đơn hàng và lưu lịch sử.
- Tab **Nhập hàng**: thêm/cập nhật sản phẩm với nhiều mã OEM thay thế.
- Tab **Lịch sử bán**: hiển thị các đơn đã lưu trong `localStorage`.

## Chạy nhanh

```bash
python3 -m http.server 4173
```

Mở `http://localhost:4173`.
